# 第一批：全局计划是否仍然合理

结论：**目标仍有价值，但现有执行计划不宜按旧勾选和旧依赖直接续跑。** 先对齐有效裁决、生产消费者和验收范围，再决定下一轮资源投入。不是推翻重来，也不是因为已经投入很久就降低门槛。

范围、版本与来源编号见 [证据索引](evidence.md)。本批为计划层全覆盖与实现入口盘点；深入核验分属后续三批。覆盖全部域不等于逐条设备 scenario 已执行。

## 1. 三种成功被叠在了一起

| 目标 | 独立判据 | 不能替代它的结果 |
|---|---|---|
| 教学 | 学生能解释、重现小实验、理解负结果和边界 | 有很多代码、运行窗口或术语 |
| 研究 | 同一任务和受控条件下比较配方，报告不确定性与负结果 | tiny loss 下降、随机教师缓存命中 |
| 工程 | 正式入口调用正确实现，目标范围数值与资源预算成立 | 独立 kernel 全绿、CPU 替身测试、单形 PASS |

原计划同时追求三者并非错误；问题是阶段出口没有持续区分它们。例如“研究车能算”可形成有价值教材，但不能直接释放正式训练任务。[G01–G06]

## 2. 决策演变：授权转向与文档漂移分开看

| 时点／来源 | 记录中的有效变化 | 需要重新协调的旧表述 |
|---|---|---|
| P1 教师版 proposal | 从零训练、MPS-only，明确裁剪学生版跨后端等要求 | 不能按完整学生作业要求反判教师版缺功能 |

| P2 10-05 proposal/design | 云端 910B、同基座三栈、教师许可边界、成本报价 | design Non-Goals 仍残留“不做 Ascend/backbone 内核接入” |
| P2 10-07 design D6/D13 | 渐进替换；后续裁决 C5 挂起、p2-13 唯一主线 | 顶层图仍按 C1→C2→C3→C4→C5 表达；“底座永远可跑”不是全部目标模型证明 |
| p2-13 10-08 至 10-11 design | 编译本地化；标量正确性与 cube 性能研究分离 | 最初“补头即可移植”、短卡窗估算不能继续无条件沿用 |

这些变化的来源是仓库保存的裁决记录，不是本轮重新授权。对无法取得原始会话的条目，只报告“计划记录如此”，不补造用户意图。[G01–G06]

## 3. P1 十域全覆盖矩阵

域的原始承诺来自归档四件套；当前实现与证据入口见 P101–P106。`scratch/` 保持冻结。

| 域 | 原承诺与承载物 | 实现／消费者 | 证据范围与欠账 | 后续核验 |
|---|---|---|---|---|
| p1-01 data-schema | typed 样本、qtype、校验 | data/schema → decision、SFT、eval | 有契约测试；score 类型能力与实际评测覆盖分开 | 数据分割、各 qtype 覆盖 |
| p1-02 run-notebook | config/metrics/notes 溯源 | runs/context → 训练与评测 | 有真实 run；模板存在不等于结论完整 | 指标、版本与结论行对账 |
| p1-03 tokenizer | BPE、字母单 token | lang/bpe → 模型与读出 | 自训词表在；P1/P2 字母 ID 不同 | 往返、单 token、加载路径 |
| p1-04 mps-kernels | 四类内核、参考与 fallback | kernels → parity／autograd | 独立对拍与真实模型调用不是同一面 | 公共 forward 正负路径 |
| p1-05 calibration | 温度拟合、ECE、随机基线 | calibrate → S3/eval | tiny 改善和正式档恶化都有记录 | 独立校准集与指标解释 |
| p1-06 decoder-model | 因果 decoder、保存加载 | model → S1/S2/predict | 模型存在；内核开关与 mask 会改变路径 | 加载、掩码、反向消费者 |
| p1-07 decision-program | render/readout/temperature/wide | decision → 两阶段 | 核心共享契约，有单测 | 零生成、选项映射、两阶段 diff |
| p1-08 pretrain-pipeline | 自训、checkpoint、采样 | learning/s1 → SFT | tiny 与后续正式档分开；loss 不等于可读性 | token/参数口径与人工判定 |
| p1-09 sft-pipeline | 决策监督与留出集 | learning/s2 → 校准与评测 | 有运行；数据来源和切分需要再核 | 模型身份、训练／测试隔离 |
| p1-10 eval-harness | 四轴报告与复现 | eval/predict/report → 交付 | quality、parity、speed 可走不同实现 | 入口归属、样本量、裸克隆 |

归档账面为 66/66 孙任务、一级 14/14；这是历史记录，不将其换算为当前完成百分比。P1 教师版没有承诺交付完整服务端，因此不能把 `scratch/serving` 只有规划说明判成该阶段漏做；若文档声称已有服务，才属于声明偏差。[G01]

## 4. P2 十三域全覆盖矩阵

| 域 | 原承诺 | 实现入口／消费者 | 当前证据边界与阻塞 | 下一步 |
|---|---|---|---|---|
| p2-01 backbone-assets | 0.8B 获取、接缝、布局转换 | assets → build_student；backbone/layout 独立路径 | 真载重历史证据；一级、二级账目不一致；布局消费需核 | 区分加载验收与自研栈接线 |
| p2-02 teacher-adapters | 三教师与真实路径 | teachers → 缓存 → sft/opd | 4B 获取不等于完整加载；scaffold 缓存不是真教师知识 | 真教师任务单列，不追认替身 |
| p2-03 eval-registry | pin、六轴、数据来源 | registry/run → 训练、评测 | 数据就绪不等于模型得分；train split 已有 | 检查每个训练入口与内容去重 |

| p2-06 opd-gkd | on-policy/per-token reverse KL | production/opd | 实际选项级 forward KL、无正式 run | 先裁定算法契约，再训练 |

| p2-11 rl-rlcd | RLCD、verifier、校准 | 正式源码尚缺 | 零勾选属正常未完成；探索日志不能替代实现 | 待前置并保留负结果 |

## 5. 当前计划的主要不合理处

### 5.1 进度的计量单位不一致

顶层按域和云端阶段记账，p2-13 tasks 混合已废路线、当前实现和新出口，run 文档又重用了任务编号。例如 W12 的 T5 是收尾，而 HANDOFF 的 T5 是精度重测。读“下一项 T5”不足以定位授权和判据。[G03、G06]

建议：下一轮每项引用“文件＋节＋任务编号＋版本”，为旧项标明被谁替代；本轮不改这些文件。没有统一编排文档是症状，真正风险是同一任务的状态、输入和出口不唯一；不为补齐模板而另造重复台账。

### 5.2 组件成功没有接上生产成功

P1 独立 parity 与 Decoder.forward、P2 LoRA 旁路与 backbone、自研产品 gdn_asc 与 TA v3 候选都是不同语义单元。它们可以独立正确，也可以在集成时出错。下一轮的最小关键项应包含公开入口和负向对照，不能只有“实现一枚 kernel”。[P101、P203、A08]

### 5.3 验收标准随局部排障发生漂移

`rel`、逐元素匹配率、全局最大绝对误差回答不同问题；低精度深链难做，不等于某项指标在数学上不可达到。fp32、tail、DK≠DV、特殊值的原承诺与当前支持状态分别列出，不能用“主档通过”隐式删除旧要求。[G05、A01–A04]

### 5.4 缺乏当前资源预算，不应继续沿用旧工期承诺

原计划的 C2=4–8h、每次卡窗≤10min是规划估算，W11 已有单腿超时上限远大于该窗口的脚本。它们不能同时作为当前预算。没有完整计费数据，不给累计费用；没有完整重写原型，不承诺两车完成或性能下降至 0.3ms/chunk。[G03、G05、A06]

### 5.5 “先把 GDN 全部做好”可能过粗，但不能自行解除挂起

C5 等待的真正技术条件应是目标模型的可微 forward/backward、内存与吞吐可接受，而不是某一目录完成。是否允许先用经验证的底座推进实验，属于用户取向；旧“torch_npu 健康”证据若来自不同模型或只测前向，不足以证明该替代路线已就绪。

## 6. 本批建议与未决项

建议保留：决策契约、同基座控制变量目标、独立参考、失败记录、训练数据隔离、渐进替换思想。

建议补证：真实教师、真实模型与算子消费者、跨形数值、指标合法性、同条件性能、运行环境和费用。

待用户最终裁定：本轮优先交付教学与研究候选，还是完整训练系统；GDN 支持范围是否允许调整；性能硬预算与结构门槛如何关联；C5 何时解除挂起。第五批给出带前置和出口的建议，不在这里默认回答。

本批没有批准改变数值门槛、下线旧机制或重写整套实现。后续批次将用代码与受控实验检验以上判断。
